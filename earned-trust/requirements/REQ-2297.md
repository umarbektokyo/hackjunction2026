# REQ-2297 — Add ExcludeFromCodeCoverage attribute to generated code

Source: https://github.com/MessagePack-CSharp/MessagePack-CSharp/issues/2297 (enhancement)

## Intent
Generated formatters and resolvers are hard to unit-test and distort coverage numbers in large
projects. All code emitted by the source generator should carry `[ExcludeFromCodeCoverage]`
(optionally also `[GeneratedCode]`). A configuration switch is optional.

## Functional requirements
- F1. Every type the generator emits (object formatters, string-key formatters, enum formatters, union formatters, resolver, composite resolver, nested helper classes) is decorated with `System.Diagnostics.CodeAnalysis.ExcludeFromCodeCoverageAttribute`.
- F2. Generated code still compiles on every target the generator supports, including targets where the attribute type or its applicability differs (netstandard2.0, .NET Framework).
- F3. Verified snapshot files are updated to match the new output, with no other differences.

## Non-functional requirements
- N1. No run-time behaviour change in serialization.
- N2. No unrelated dependency or build changes.
