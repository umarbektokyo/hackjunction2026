# REQ-2234 — The analyzer does not work if SuppressSourceGeneration = true

Source: https://github.com/MessagePack-CSharp/MessagePack-CSharp/issues/2234 (bug, regression since 3.1.1)

## Intent
`[MessagePackObject(SuppressSourceGeneration = true)]` only opts a type out of source generation.
Such a type is still serialized at run time by the dynamic resolvers, so the analyzer must still
validate its contract (keys, AllowPrivate, member types, accessibility). Since 3.1.1 the analyzer
reports nothing for these types; it worked in 3.1.0.

## Functional requirements
- F1. For a type with `SuppressSourceGeneration = true`, the analyzer reports MsgPack004 (member needs Key/IgnoreMember), MsgPack005 (key problems), MsgPack015 (AllowPrivate required), MsgPack003 (member type must be MessagePackObject) and MsgPack012 (accessibility) exactly as it does for a type without the flag.
- F2. Generation-only diagnostics (MsgPack011 partial class, MsgPack016/017 AOT) are not reported for these types.
- F3. No formatter is generated for these types (existing behaviour preserved).

## Non-functional requirements
- N1. Regression tests cover F1 for at least MsgPack004 and MsgPack015 and prove the analyzer runs on a suppressed type.
- N2. No unrelated dependency or build changes.
